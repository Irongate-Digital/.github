# .github

Organisation profile and default community health files for
[Irongate Digital](https://github.com/Irongate-Digital).

- `profile/README.md` — the organisation profile page.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` — defaults inherited by every
  repository in the organisation that does not define its own.
- `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md` — default templates.

Repository-specific files take precedence over these defaults.
