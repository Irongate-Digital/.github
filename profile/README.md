# Irongate Digital Solution Ltd

Backend, API and integration platform for prepaid top-up, game top-up and payment
distribution.

## Engineering

Our repositories follow a common baseline: automated dependency updates with security
alerts, supply-chain scanning on every pull request, CI gates (tests, lint, build) before
merge, explicit least-privilege workflow permissions, and Conventional Commits.
