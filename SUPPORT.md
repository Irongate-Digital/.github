# Support

## Getting help

| I need… | Go to |
| --- | --- |
| To report a bug | [Open a bug report](https://github.com/Irongate-Digital/.github/issues/new?template=bug_report.md) in the relevant repository |
| To request a feature | [Open a feature request](https://github.com/Irongate-Digital/.github/issues/new?template=feature_request.md) in the relevant repository |
| To report a **security** issue | **Do not open a public issue.** See [SECURITY.md](SECURITY.md) |
| Account, access or operational help | techsupport@irongatedigital.com |
| Engineering questions | tech@irongatedigital.com |

## Before opening an issue

- Search existing issues first — it may already be reported.
- Include the repository, environment (production / staging / sandbox / local) and any error
  output, trace or event IDs.
- Never paste secrets, credentials or real customer data into an issue.

## Service status

Uptime and health checks are monitored internally. If you suspect an outage, contact the team
directly at techsupport@irongatedigital.com rather than opening an issue.
